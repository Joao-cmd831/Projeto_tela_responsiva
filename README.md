# Trabalho_Web
Projeto de responsividade como atividade acadêmica.

# Sobre o projeto
Este aplicativo foi desenvolvido com foco na responsividade para dispositivos menores. O objetivo foi desenvolver um frontend de um site.

# Funcionalidades
- Tela principal.
- Navegação entre as seções
- Tela de contato.
- Interface adaptada para iPad.
